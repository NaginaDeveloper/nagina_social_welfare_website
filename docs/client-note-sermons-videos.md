# Sermons & Videos update — note for Nagina Social Welfare

**Date:** 18 September 2026  
**Live page:** https://www.naginasocialwelfare.co.uk/sermons/

---

## What’s new

The Sermons page now brings together your video channels in one place, with less clutter and easier search.

### 1. Latest videos (updated automatically)
Visitors see the newest clips from:

| Source | Channel |
|--------|---------|
| **Nagina TV** | The YouTube channel used for the Seedha Rastah bayanat |
| **Nagina Social Welfare** | Your organisation YouTube channel |
| **TikTok** | [@nagina.social.wel](https://www.tiktok.com/@nagina.social.wel) |

These lists refresh automatically when the site is built/deployed, and (when the live API is active) about every few hours without a full website republish.

### 2. One search for everything
A single search box finds videos across:

- Latest Nagina TV uploads  
- Latest Nagina Social Welfare YouTube uploads  
- The full **Seedha Rastah sermon archive** (about 242 titled bayanat)

Results are labelled by source so people can see where each clip came from.

### 3. Cleaner page layout
We no longer show all 242 sermons as a long grid by default.  
Instead:

- **Browse** → latest clips from each channel  
- **Search** → find older bayanat in the archive  

That keeps the page easier to use on phones and desktops.

### 4. TikTok in the footer
The site footer now includes a TikTok icon linking to [@nagina.social.wel](https://www.tiktok.com/@nagina.social.wel), next to Facebook, Instagram and YouTube.

---

## What you may want to check

1. Open https://www.naginasocialwelfare.co.uk/sermons/  
2. Confirm the latest Nagina TV / organisation YouTube / TikTok clips look right  
3. Try searching for a known bayan title from the Seedha Rastah collection  
4. Check the TikTok icon in the website footer  

---

## Notes

- The 242 Seedha Rastah sermons remain available through search; they are not removed.  
- YouTube only publishes a limited “latest uploads” feed without special API access; the Seedha Rastah archive is what lets us keep older titled bayanat searchable.  
- New TikTok or YouTube posts should appear in the “Latest” sections after the next automatic refresh (or after the next website deploy).

If you’d like any wording changed, or more/fewer latest clips shown, tell us and we can adjust.
