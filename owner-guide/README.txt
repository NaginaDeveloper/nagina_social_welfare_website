Nagina Social Welfare UK — Owner Guide
======================================

Shareable map of every navigation URL on the live website,
with screenshots and clickable links.

HOW TO SHARE
------------
1. Open owner-guide/index.html in a web browser
   (double-click the file, or drag it into Chrome/Safari).

2. To send as a single PDF:
   Open the HTML → Print → Save as PDF
   (images are embedded via relative paths; for PDF, print
   from a browser after opening the local file).

3. Or zip the whole owner-guide/ folder and email it —
   keep index.html and screenshots/ together.
